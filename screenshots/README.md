# Screenshots & Visual Assets

This directory stores visual documentation, interface captures, and design milestone screenshots for the WebMate project.

## Conventions

1. **File Naming**:
   - Use lowercase kebab-case prefixed with the feature area or milestone:
     - `extension-popup-v0.1.png`
     - `character-docked-idle.png`
     - `element-inspector-overlay.png`
     - `chat-drawer-expanded.png`
2. **Format & Optimization**:
   - Use PNG format for crisp UI previews or WebP for compressed documentation images.
   - Optimize images prior to committing to keep git repository size lean (e.g. compress via ImageOptim or TinyPNG).
3. **No Sensitive Data**:
   - Never capture screenshots containing proprietary credentials, personal browsing history, private user tokens, or real API keys.
4. **Third-Party Copyright Notice**:
   - Screenshots must not contain unlicensed commercial character artwork or proprietary media assets. Use project-approved vector placeholders.
